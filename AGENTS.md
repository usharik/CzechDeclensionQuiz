## Project

  Analytics/Crashlytics). Modules: `:app`, `:database`, `:utils`, plus the Appium suite in `ui-tests/`.

  Edit `utils/corpus/manual_translations.py` or `utils/corpus/translations/*.txt` and rebuild; never

  [`ADJECTIVES_VERBS_NOTES.md`](ADJECTIVES_VERBS_NOTES.md).

## Build and test

```bash
./gradlew assembleDebug          # debug APK
./gradlew test                   # unit tests (CI does not run them; run them yourself)
./gradlew compileDebugAndroidTestKotlin   # compile instrumented tests
scripts/deploy-debug.sh [serial] # install the debug APK on a connected device
```

- The development VM has no Android emulator. Verification there stops at the build, unit tests and
  compiling androidTest sources; say so instead of claiming the UI was exercised. The GitHub
  `UI Tests` workflow (`.github/workflows/ui-tests.yml`) is the only device run; see
  [`.github/copilot-instructions.md`](.github/copilot-instructions.md) for reading its reports.
- Ads go through `AdsPolicy.areAdsEnabled()` (`app/src/main/kotlin/com/usharik/app/ads/Ads.kt`);
  instrumented tests replace the `AdManager` via `App.createAdManager()`.

## Versioning

- `VERSION` holds `MAJOR.MINOR`; `versionCode = MAJOR * 100 + MINOR` (`gradle/version.gradle`).
- A push to `main` runs `build.yml`, which commits `Bump version to X [skip ci]`. `VERSION` on `main`
  is therefore the next, not yet uploaded, version. Use a branch + PR to run CI without a bump.
- The `gh` token on the VM lacks the `workflow` scope: pushes that touch `.github/workflows/*` are
  rejected until the owner runs `gh auth refresh -s workflow`.

- Service account `github-play@our-time-371813.iam.gserviceaccount.com` has access to this app.
  It is shared with MySongbook: the key lives in `~/src/MySongbook/pc-api-key.json`, and
  `pc-api-key.json` in this repo is a gitignored symlink to it (`fastlane/Appfile` reads it, or

  Never commit, print or copy the key elsewhere.
- Release signing: `signing.*` in `local.properties` (gitignored) point to `~/src/my_key_store`, alias
  `my_first_key`, the same upload key as CI (`KEYSTORE_BASE64` secret). `app/google-services.json` is local
  and gitignored too.
- Read-only checks are safe to run at any time, e.g.
  `fastlane run google_play_track_version_codes track:production`.
- Direct Android Publisher API calls (e.g. one-time products for in-app billing, which fastlane does
  not cover) can use a token from the same key:

  ```bash
  TOKEN=$(ruby -e 'require "googleauth"; puts Google::Auth::ServiceAccountCredentials.make_creds(
    json_key_io: File.open("pc-api-key.json"),
    scope: "https://www.googleapis.com/auth/androidpublisher").fetch_access_token!["access_token"]')
  curl -H "Authorization: Bearer $TOKEN" \
    https://androidpublisher.googleapis.com/androidpublisher/v3/applications/com.usharik.app/oneTimeProducts
  ```

  The legacy `inappproducts` endpoint answers 403 "Please migrate to the new publishing API"; use
  `oneTimeProducts` / `subscriptions`.

## Deployment

Uploading a build, changing the store listing or creating/changing Play products is outward-facing:
do it only when the owner asks for it in the current task.

Two equivalent routes, both upload the signed release APK with `distribution/whatsnew/*` as release notes:

1. **GitHub Actions** (primary): `.github/workflows/deploy.yml`, run manually with a track, or push a
   `v*.*.*` tag for production.
2. **Fastlane** (local alternative, `fastlane/Fastfile`):

   ```bash
   fastlane build_release                     # signed APK only, nothing uploaded
   fastlane deploy                            # tests + build + upload to internal
   fastlane deploy track:production skip_tests:true
   fastlane texts                             # store listing texts from fastlane/metadata
   fastlane metadata                          # listing texts + images + screenshots
   ```

   `deploy` refuses to run when the `VERSION` code is not above every code already on Play; bump
   `VERSION` (and commit it) first. It builds the working tree as is, so commit or stash unrelated
   changes before releasing.

More detail for humans: [`DEPLOYMENT_GUIDE.md`](DEPLOYMENT_GUIDE.md), [`distribution/README.md`](distribution/README.md).
